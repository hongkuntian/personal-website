# Frontend Design

This skill guides creation of distinctive, production-grade frontend interfaces that avoid generic "AI slop" aesthetics. Implement real working code with exceptional attention to aesthetic details and creative choices.

The user provides frontend requirements: a component, page, application, or interface to build. They may include context about the purpose, audience, or technical constraints.

## Design Thinking

Before coding, understand the context and commit to a bold aesthetic direction:
- Purpose: Identify what problem the interface solves and who uses it.
- Tone: Pick a clear style direction such as brutally minimal, maximalist chaos, retro-futuristic, organic/natural, luxury/refined, playful/toy-like, editorial/magazine, brutalist/raw, art deco/geometric, soft/pastel, or industrial/utilitarian.
- Constraints: Capture technical requirements such as framework, performance, and accessibility.
- Differentiation: Define the one memorable quality that makes the output stand out.

Choose a clear conceptual direction and execute it with precision. Bold maximalism and refined minimalism both work when the design is intentional.

Then implement working code (HTML/CSS/JS, React, Vue, etc.) that is:
- Production-grade and functional
- Visually striking and memorable
- Cohesive with a clear aesthetic point of view
- Meticulously refined in detail

## Frontend Aesthetics Guidelines

Focus on:
- Typography: Choose beautiful, distinctive type pairings. Avoid generic defaults like Arial, Inter, Roboto, and system stacks. Prefer a characterful display font plus a refined body font.
- Color and Theme: Commit to a coherent palette with clear hierarchy. Use CSS variables for consistency. Favor a strong primary direction with deliberate accents.
- Motion: Add meaningful animation and micro-interactions. Prioritize one high-impact entrance sequence with staggered reveals. Use hover and scroll behavior that reinforces the concept.
- Spatial Composition: Use intentional asymmetry, overlap, diagonal flow, grid breaks, and controlled use of density or negative space.
- Backgrounds and Visual Details: Build atmosphere with textures, gradient meshes, geometric patterns, layered transparencies, custom shadows, decorative borders, and grain overlays when appropriate.

Avoid generic patterns: overused fonts, cliched purple-gradient-on-white aesthetics, predictable layouts, and interchangeable component structures.

Interpret requirements creatively and make context-specific choices. Vary theme direction, typography, and composition across outputs. Do not converge on repetitive defaults.

Match implementation complexity to the vision:
- Maximalist designs: Use richer composition, interaction, and visual systems.
- Minimal or refined designs: Use restraint, precise spacing, and subtle but deliberate details.

Aim for intentional, memorable frontend work with clear craft in both aesthetics and implementation.
